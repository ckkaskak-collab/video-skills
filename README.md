# Video Skills


三个视频制作 Skill 的完整目录备份。xilo-knowledge-video 最新版本为 2026-09-20，其余两个包打包日期为 2026-09-15。


- `anything2explainer.zip`：黑底 MG 科普讲解视频，含模板、脚本、参考和样例。
- [xilo-knowledge-video.zip（2026-09-20 完整包）](https://github.com/ckkaskak-collab/video-skills/releases/download/xilo-2026-09-20/xilo-knowledge-video.zip)：A-roll 角色与 B-roll 知识视频工作流，含原文提示词、角色参考、脚本和六组 17 张连续图片帧样图。完整包现存于 [Release](https://github.com/ckkaskak-collab/video-skills/releases/tag/xilo-2026-09-20)，共 54 个文件、43.7 MB；仓库根目录同名 ZIP 保留为 2026-09-15 历史备份。
- `paper-outline-video.zip`：米白纸感彩色描边知识视频，含 Remotion 模板和参考。


## 使用


下载所需 ZIP 并解压，将其中同名文件夹放入 Codex skills 目录（通常为 `~/.codex/skills/`）。已有同名 Skill 时先备份，避免覆盖个人改动。


保留原文件及目录结构，仅排除依赖、缓存和系统杂项。每个压缩包已逐文件比对验证。Skill 引用的外部工具、服务和目录外资源仍需单独配置；封面 Skill 等关联技能不包含在本次三个包内。
